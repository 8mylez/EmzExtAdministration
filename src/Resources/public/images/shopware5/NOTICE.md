# Shopware 5 backend artwork

These unmodified image assets originate from shopware AG's Shopware 5 backend:
https://github.com/shopware5/shopware/tree/63ff03085ce80e11d2cdad01b4481ba7ef39b9bd/themes/Backend/ExtJs/backend/_resources

Source revision: `63ff03085ce80e11d2cdad01b4481ba7ef39b9bd` (branch `5.7`).
The exact upstream root license is retained in `LICENSE.shopware5.txt`.
Shopware and its logo are trademarks of shopware AG.

The plain background, taskbar texture, window texture, window tool sprite
and menu icons are used to reproduce the Shopware 5 appearance. The application still
runs on Shopware 6 with Ext JS 7. The accompanying CSS adapts that appearance
to Ext JS 7; the original Ext JS 4 theme is not loaded.
The Shopware 5 logo artwork is not displayed. Login and desktop branding use
the logo supplied by the installed Shopware 6 administration and a version label.

The upstream repository describes Shopware as GPLv3; its license file also
contains AGPLv3 terms and additional permissions. Preserve the supplied upstream
license and notices with these assets. This notice does not replace or alter
their original licensing terms.

The Shopware 5 icon sprites and their unmodified style sheets
(`core-icon-set.css`, `core-icon-set-new.css`) are stored in `../../shopware5/`
with their upstream directory layout and provide the main menu icons.
